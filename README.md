# Helora

The front desk that thinks.

Helora is an AI voice receptionist for dentists, restaurants, and hotels. One product. Preset conversation templates you adopt or rewrite in plain English. Keep the number you already have.

This repository is the customer-facing site.

## Stack

- Next.js (App Router)
- Three.js via React Three Fiber
- Tailwind CSS
- Vercel

## Local

```bash
npm install
npm run dev
```

## Demo requests

`POST /api/demo` logs a qualified request. Wire email or a CRM next.
